# 📊 Clean a Messy Excel File Using n8n

An automated Excel data cleaning system built with **n8n** to simplify data processing, improve data quality, and reduce repetitive manual spreadsheet work.

## 🚀 Project Overview

Messy spreadsheet data can contain inconsistent formatting, duplicate records, missing values, and incorrect data formats. Cleaning this information manually can be time-consuming.

This project demonstrates how workflow automation can help process Excel data, standardize records, and improve data consistency using n8n.

## ✨ Key Features

- 🧹 **Automated Data Cleaning:** Streamlines repetitive spreadsheet cleaning tasks.
- 🔍 **Data Validation:** Helps identify invalid or inconsistent data.
- 🔄 **Data Standardization:** Supports consistent formatting across records.
- 📋 **Duplicate Handling:** Helps identify or remove duplicate entries when configured.
- ⚠️ **Data Quality Checks:** Helps detect missing or unexpected values.
- 📁 **Spreadsheet Processing:** Automates reading and processing spreadsheet files.
- ⚡ **Workflow Automation:** Reduces manual data preparation efforts.

## 🛠️ Tech Stack

- **n8n** – Workflow automation and orchestration
- **Excel / XLSX** – Spreadsheet data processing
- **Data Transformation** – Cleaning and standardizing records
- **Python** – Custom data processing, if configured in the workflow

## ⚙️ How It Works

1. The workflow receives or accesses an Excel file.
2. Spreadsheet data is extracted for processing.
3. Data is checked for inconsistencies and quality issues.
4. Configured cleaning rules standardize the data.
5. Duplicate or invalid records are handled according to the workflow rules.
6. The processed data is prepared for export or further use.

## 🎯 Real-World Use Cases

- Cleaning customer databases
- Standardizing sales and inventory records
- Preparing datasets for analysis
- Validating business spreadsheets
- Removing duplicate records
- Automating repetitive Excel data preparation
